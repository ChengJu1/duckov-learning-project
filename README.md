# Duckov Learning Project

一个以《逃离鸭科夫》为参考、用于学习游戏开发和 AI 辅助大型工程维护的个人项目。

## 当前状态

阶段 0、1、2 已完成。当前原型具备基础战斗、成功撤离、死亡与重新出发的完整循环；五个功能里程碑通过人工验收，收尾回归共 98 项测试通过。阶段 3 尚未开始。

## 最小可玩循环（暂定）

1. 玩家进入一张小型测试地图。
2. 玩家移动并拾取一个物品。
3. 玩家抵达撤离点。
4. 成功撤离后，物品进入局外库存。
5. 玩家可以再次出发。

这个循环用于尽早验证“进入地图 → 搜集 → 承担风险 → 撤离 → 保留收益”，暂不追求完整战斗、复杂 AI 或商业级内容。

## 近期阶段

## 本地运行

首次进入项目时创建虚拟环境并安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --editable ".[dev]"
```

启动当前窗口原型：

```powershell
.\.venv\Scripts\python.exe -m duckov_game
```

窗口中使用 `WASD` 或方向键移动黄色玩家方块；玩家身上的浅黄色短线会朝向鼠标，点击鼠标左键沿该方向发射弹丸。接触绿色物品后，物品消失且携带数量增加；随后进入左侧蓝色区域完成撤离。物品会结算到 `Stash items`，按 `R` 开始下一局。空手不能撤离，也不能在局中重开。

红色敌人从右上方出生，以 90 像素/秒追踪玩家（玩家为 240 像素/秒），中心距离约 56 像素时停止；玩家走远后继续追踪。初始生命值为 100，每颗命中的弹丸造成 25 伤害并消失。命中四次后敌人消失，显示 `Enemy defeated`。敌人不会阻挡玩家移动，击败敌人不是撤离前提。

玩家初始 100 血。在敌人中心距离 64 像素内连续停留 1 秒会受到一次 20 点伤害，持续停留会重复受伤；跑出范围会取消攻击计时。橙色条表示敌人攻击准备进度，玩家受伤时短暂闪红，左上角显示玩家血量。玩家生命值归零后显示 `YOU DIED`，冻结本局并丢失本局携带物，已有 stash 不变。成功撤离或死亡后都可按 `R`：恢复双方出生位置、满血、物品和攻击计时，stash 保留。

注意：当前 stash 仅在同一次程序运行的多局之间保留，关闭程序后清空；尚未实现磁盘存档。

运行自动化测试：

```powershell
.\.venv\Scripts\python.exe -m pytest
```
